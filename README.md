You just need to clone the whole project into the existing directory and overwrite the existing files.

You may find the following commands useful.

**How to download the project:**
```bash
cd Weather_Station
git clone https://github.com/Minemetero/Weather_Station.git
```

**Setting up the environment and executing the code:**
```bash
source .venv/bin/activate
python main.py
```
